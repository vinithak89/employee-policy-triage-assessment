# Employee Policy Triage UI

React + Vite + TypeScript frontend for the Employee Policy and Reimbursement Triage assessment.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui-compatible component structure
- TanStack React Query

## Start

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`. The Spring Boot API must be running on `http://localhost:8080`.

The UI is a presentation layer over the same Spring Boot APIs used by Swagger.
